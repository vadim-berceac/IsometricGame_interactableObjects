## Interactables (Интерактивные компоненты)

### DoorController
Компонент для управления движением дверей с поддержкой нескольких режимов. Реализует:
- **Два режима движения**: поворот створок двери (Rotate) или их скольжение (Slide)
- **Состояния двери**: открыта (Open), заперта (Locked), заблокирована (Blocked)
- **Три состояния створок**: каждая створка отслеживает свою позицию открытия/закрытия
- **Асинхронная анимация**: использует DOTween для плавного движения створок параллельно
- **Автоматическое закрытие**: опциональное автоматическое закрытие двери после задержки
- **События Unity**: onOpenStart, onOpenEnd, onCloseStart, onCloseEnd для связи с другими компонентами
- **Визуальные индикаторы**: спрайты для отображения текущего состояния двери

### Elevator & ElevatorPath
Система лифта для вертикального перемещения:
- **ElevatorPath**: хранит точки остановок лифта и параметры сегментов между ними
  - Список точек остановки (ElevatorStopPoint) с метками и высотами
  - Сегменты пути (ElevatorSegment) с настраиваемой скоростью и кривой ускорения
  - Синхронизация количества сегментов с числом точек остановки
  - Визуализация пути через Gizmos

- **Elevator**: управляет движением лифта между точками
  - Методы перемещения: MoveToIndex, MoveToNext, MoveToPrevious, MoveToFirst, MoveToLast
  - События: onDeparture (при отправлении), onArrived (при прибытии)
  - Асинхронное движение с поддержкой отмены
  - Интеграция с AnimationCurve для контроля ускорения на каждом сегменте

### InteractAnimation
Универсальный компонент для воспроизведения последовательности анимаций при взаимодействии:
- **Структурированное воспроизведение**: enter clip → основные клипы → exit clip
- **Гибкая конфигурация клипов**:
  - Опция рандомизации порядка воспроизведения
  - Зацикливание всего блока клипов до прерывания
  - Поддержка looped анимаций
- **Blending переходов**: настраиваемое перекрытие между клипами (enter/exit blend length)
- **Маски костей**: каждый клип может использовать AvatarMask для анимации только части модели
- **Аддитивные анимации**: поддержка смешивания анимаций
- **Прерывание**: возможность прервать воспроизведение последовательности
- **События**: onInteractEnter, onInteractExit, onClipStarted для синхронизации с другой логикой

### InteractAnimationEvents
Система для срабатывания событий в определённые моменты времени воспроизведения анимаций:
- **Отслеживание времени клипа**: нормализованное время (0-1) с возможностью применения кривой трансформации
- **Динамические события**: для каждого клипа можно задать массив событий с точным временем срабатывания
- **Гистерезис срабатывания**:
  - TriggerTolerance: допуск на достижение времени события (± от целевого времени)
  - ResetHysteresis: расстояние отката, необходимое для повторного срабатывания события
- **Вызовы событий**: каждое событие имеет UnityEvent, общее OnAnyEvent для всех событий, и event action OnEventTriggered(string name, string data)
- **Настраиваемый интервал опроса**: проверка прогресса каждый кадр или с заданным интервалом
- **Динамическое управление**: методы AddEventForClip и RemoveAllEventsForClip

### InteractMotion
Компонент для перемещения и поворота персонажа во время взаимодействия:
- **Выбор целей**:
  - Контроллер: персонаж из события или фиксированный
  - Целевая позиция: фиксированный трансформ или сам взаимодействующий объект
- **Три типа входного движения**: только поворот, только движение, движение + поворот
- **Четыре типа выхода**: остаться на месте, вернуться в исходную позицию, вернуться с поворотом, переместиться в точку выхода
- **Отсрочка входа**: задержка перед началом движения
- **Игнорирование коллизий**: отключение коллизий между персонажем и объектом во время взаимодействия
- **DOTween анимация**: плавное движение и поворот с кривыми ускорения
- **События**: onEnterMotionEnd, onExitMotionStart

### LadderInteractor
Компонент для взаимодействия с лестницей:
- **Вход на лестницу**: позиционирование персонажа с плавным переходом (enterDuration, enterEase)
- **Движение по лестнице**: вертикальное перемещение с контролем скорости (walkSpeed, runSpeed)
- **Ориентация**: постоянный поворот к направлению лестницы
- **Отслеживание направления**: определение направления движения (вверх/вниз) из input по оси Y
- **Связанные концы**: LadderInteractor может быть связан с другим экземпляром (OtherEnd) для двусторонней лестницы
- **Выход с лестницы**: движение к точке выхода с плавным переходом (exitDuration, exitEase)
- **Управление stopper**: автоматическое отключение коллайдера-стопора во время входа и включение после
- **События**: onInteractEnter, onInteractExit

### InteractionVolume & InteractOnTrigger
Вспомогательные компоненты для определения зон взаимодействия:
- **InteractionVolume**: триггер-объем для обнаружения персонажа (поддерживает Box и Sphere формы)
- **InteractOnTrigger**: простой адаптер для вызова события при входе/выходе

### Прочие компоненты
- **ElevatorDoorAdapter**: адаптер для связи лифта с дверьми
- **InteractableObject**, **InteractObjectSpawner**: базовые классы и утилиты
- **LadderStopper**: компонент-стопор для ограничения движения на лестнице

## Tools — LadderConstructor

Инструмент для процедурного построения лестниц в редакторе Unity:

### Основной функционал
- **Создание ячеек лестницы**: автоматическое инстанцирование ячеек из префаба с позиционированием
- **Параметризация**:
  - `cellPrefab`: префаб одной ячейки (или префаб самого скрипта для использования)
  - `cellCount`: количество ячеек
  - `cellHeight`: высота одной ячейки (определяет расстояние между ячейками)
  - `cellPivotOffset`: смещение пивота ячейки (влияет только на гизмо)

### Интерактивные зоны
- **Start Zone** (нижняя): префаб, отступ, масштаб зоны взаимодействия в начале лестницы
- **End Zone** (верхняя): префаб, отступ, масштаб зоны взаимодействия в конце лестницы
- **Автоматическая связь**: зоны автоматически связываются между собой через SetOtherEnd() для двусторонней лестницы

### Редакторские возможности
- **OnValidate интеграция**: реагирует на изменение префабов и автоматически пересчитывает лестницу
- **Undo система**: все операции регистрируются в undo/redo истории
- **Гизмо визуализация**: показывает границы лестницы, высоту и направление

### Продвинутые возможности
- **Синхронизация мешей**: при изменении исходного префаба обновляются mesh фильтры в инстанцах
- **ProBuilder поддержка**: автоматическое перестроение ProBuilder меш-компонентов через рефлексию
- **Защита от циклических ссылок**: проверяет, что cellPrefab не указывает на сам объект в сцене
- **Работа с prefab stage**: корректно работает при редактировании префаба в Prefab Mode

### API
- `Construct()`: пересчитать лестницу (добавить/удалить ячейки)
- `ClearAll()`: удалить все ячейки
- `TotalHeight`: свойство для получения общей высоты лестницы

## Editor (Редакторские расширения)

### CharacterEditor
Пользовательский инспектор для компонента Character:
- **Условное отображение**: поля для ротации к курсору видны только для типа персонажа "Player"
- **Управляемые свойства**: CharacterType, rotationToCursorSpeed, minRotationDistance, closeRotationDistance, maxCloseRotationAngle, playerLayer

### ElevatorPathEditor
Полноценный редактор для визуального проектирования пути лифта:
- **Инспектор возможности**:
  - Редактирование точек остановки (Label, Height)
  - Редактирование параметров сегментов (Speed, SpeedCurve)
  - Добавление/удаление точек
  - Выбор и подсветка активной точки
- **Scene View интеграция**:
  - Визуализация линий пути между точками
  - Цветные квадраты для каждой точки (разные цвета для start/end)
  - Интерактивные handle'ы для перетаскивания точек вверх/вниз
  - Отображение скорости над каждым сегментом
  - Подписи с номером, названием и высотой точки

### InteractAnimationEventsEditor
Специализированный редактор для управления событиями анимаций:
- **Структурированное UI**: иерархичное отображение (клипы → события → параметры)
- **Визуальное редактирование**:
  - Добавление/удаление клипов и событий
  - Slider для времени события (0-1)
  - Поля для имени события и данных
  - Настройка допуска и гистерезиса
  - Привязка UnityEvent для каждого события
- **Валидация**: проверяет соответствие TriggerTolerance и ResetHysteresis

### InteractMotionEditor
Инспектор с условным отображением для InteractMotion:
- **Динамическое UI**: поля контроллера/целей видны только при выборе соответствующих режимов
- **Использование рефлексии**: безопасное получение значений приватных enum-типов
- **Структурированное отображение**: логическая группировка параметров по назначению

### InteractVolumeEditor
Расширенный редактор для volumes взаимодействия с поддержкой Scene View:
- **Инспектор настройки**: форма, центр, размер/радиус, слои, события, гизмо
- **Scene View редактирование**: интерактивные handle'ы (BoxBoundsHandle, SphereBoundsHandle) для прямого редактирования в сцене
- **Кастомный Edit Mode**: режим редактирования вызывается через кнопку в инспекторе
- **Визуализация gizmo**: настраиваемый цвет и отображение только при выделении

### LadderConstructorEditor
Специализированный редактор для удобного создания и редактирования лестниц:
- **Inspector UI**:
  - Кнопки "+ Ячейка" и "− Ячейка" для быстрого изменения
  - Кнопка "Очистить" для удаления всех ячеек
  - Информационный блок с высотой и количеством ячеек
- **Scene View handle**: интерактивный конус-handle на верхней точке лестницы для перетаскивания и изменения высоты
- **Undo интеграция**: все действия регистрируются с понятными названиями
